# 说明

本工程适用于微瑞能源的RN8211B（A4:互感器版）开发板。

# 晶振

低速晶振：32.768K

# 外设

## EEPROM

RN8211B(C)内置 32K EEPROM，正常启动时，其地址为0x08000000.

本工程采用[FlashDB](https://github.com/armink/FlashDB.git)管理EEPROM,将EEPROM分为两个区(具体见[fal_cfg.h](fal_cfg.h)),其说明如下:

| 偏移       | 长度       | 类型       | 用途                   |
| ---------- | ---------- | ---------- | ---------------------- |
| 0x00000000 | 0x00002000 | KV数据库   | 存储设置等             |
| 0x00002000 | 0x00006000 | 时序数据库 | 存储时序数据，如电量。 |

## LCD

RN8211B(C) 支持段码屏幕。可支持多种模式。

开发板自带5位8字段码屏，共40段，共占用4个LCD COM脚及10个LCD SEG脚。其中LCD SEG脚为复用引脚，需要将功能设置为LCD。

本工程中采用8COM模式(COM引脚采用COM0~COM3，SEG引脚采用SEG20~SEG29),对应的显示缓冲为LCD_BUF16~LCDBUF25。

驱动实现见[drv_lcd.h](drv_lcd.h)与[drv_lcd.cpp](drv_lcd.cpp)。

## EMU

RN8211B(C)具有EMU(计量)模块。其具有一个电压通道(U)及两个电流通道(I1、I2，其中I1为主通道，I2为辅助通道)。

开发板上电压通道采用1:1电压互感器,分压电阻采用6个33kΩ（与原理图略有不同）,采样电阻采用49.9Ω。两个电流通道互感器采用1000:1,采用电阻采用20 Ω。

驱动实现见[drv_emu.h](drv_emu.h)与[drv_emu.cpp](drv_emu.cpp)。

## UART0

串口0引脚:P20->RX0、P21->TX0。

默认参数19200 8N1，默认运行DL/T 645协议（见DL/T 645章节，注意:某些参数与DL/T 645协议不同）。

# 栈

由于RN8211B的内存非常小,所以各任务栈均非常小，一定要注意栈的使用。

## MSP

main函数与中断函数使用的栈。

由链接脚本与启动汇编决定。

若未特殊说明，一般分配768字节(MDK见startup*.s,GCC见链接脚本)。

中断函数中不要进行复杂的操作，可用于简单标志检查与设定。

## PSP

psp由任务使用，下列为各个任务的栈。

### 空闲任务(idle)

若未特殊说明，一般为最小任务栈大小（一般是128字（512字节））。

空闲任务中不要进行复杂的操作，可用于简单标志检查与设定。

### HBox

若未特殊说明，一般是640字（2560字节）。

HBox为主任务，可进行相对复杂的操作（尤其对栈消耗较大的函数）。

**注意：HBox任务是动态创建的，需要使堆空间(内存剩余量)足够。**

# DL/T 645

[DL/T 645](../../Doc/DLT645-2007-多功能电能表通信协议.pdf)协议为多功能表协议。

本工程现支持以下功能:

- 时间同步
- 读通信地址
- 写通信地址

## 时间同步

内部时序数据库需要时间，需要通过时间同步获取时间。

## 读通信地址

一般情况下，可使用通配符地址读取通信地址（注意:只支持点对点功能）。

由于读通信地址参数固定，可使用以下数据帧读取地址。

```bash
68 AA AA AA AA AA AA 68 13 00 DF 16
```

## 写通信地址

一般情况下，当地址为全0时，可通过写通信地址命令写入地址。当地址不为0时仅可写入全0地址，写其它地址无效且不回复。

## 读数据

用户可通过数据标识读取数据。若未特殊说明，数据的低字节在前，且为BCD码数字。

| DI(DI3 DI2 DI1 DI0) | 说明                                             | 备注   |
| ------------------- | ------------------------------------------------ | ------ |
| 02 01 01 00         | 电压，2字节（4位数字），1位小数,V                |        |
| 02 02 01 00         | 电流(通道1)，3字节（6位数字），3位小数,A         |        |
| 02 02 01 01         | 电流(通道2)，3字节（6位数字），3位小数,A         | 非标准 |
| 02 03 00 00         | 有功功率(通道1)，3字节（6位数字），4位小数，kW   |        |
| 02 03 00 01         | 有功功率(通道2)，3字节（6位数字），4位小数，kW   | 非标准 |
| 02 04 00 00         | 无功功率(通道1)，3字节（6位数字），4位小数，kVar |        |
| 02 04 00 01         | 无功功率(通道2)，3字节（6位数字），4位小数，kVar | 非标准 |
| 02 05 00 00         | 视在功率(通道1)，3字节（6位数字），4位小数，kVA  |        |
| 02 05 00 01         | 视在功率(通道2)，3字节（6位数字），4位小数，kVA  | 非标准 |
| 02 80 00 02         | 电网频率,2字节（4位数字），2位小数,Hz            |        |

# UI

本工程可使用5位8字段码屏作为UI。

## 数据展示

每隔一段时间切换不同的UI。

数据展示时，UI表达如下:

- 第1位8字为字母，用于指示数据类型。
- 第2到第5位8字及3P、4P、5P用于显示数据，可现实9999以下数字。
- 1P与2P指示通道，2P指示通道1，1P指示通道2。
